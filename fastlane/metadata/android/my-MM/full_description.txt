Retro Player က သင့်ဖုန်းထဲက folder တွေကနေ သီချင်းနဲ့ audiobook တွေကို တိုက်ရိုက်ဖွင့်ပေးပါတယ်။ အော့ဖ်လိုင်းအလုပ်လုပ်ပြီး ကြော်ငြာတွေမပါဘူး၊ အကောင့်လည်းမလိုပါဘူး။

ဘာလို့ Retro Player လဲ။
• သင်ထားခဲ့တဲ့နေရာကနေ အတိအကျဆက်ဖွင့်လဲ- album၊ audiobook နဲ့ playlist တိုင်းဟာ restart လုပ်ပြီးနောက်မှာတောင် သူ့ရဲ့နေရာနဲ့ speed ကို ထိန်းသိမ်းထားပေးပါတယ်။
• library scan မလုပ်ရဘူး- index တည်ဆောက်စရာမလိုသလို စောင့်ဆိုင်းစရာလည်း ဘာမှမရှိပါဘူး။ folder တစ်ခုထည့်ပြီး နားထောင်လို့ရပါပြီ။ app က folder တစ်ခုကို ဖွင့်မှသာ ဖတ်ပေးပါတယ်။
• သင့်ဖိုင်တွေက မထိဘဲရှိနေမှာပါ- app က သင်ရွေးချယ်ထားတဲ့ folder တွေကိုပဲ မြင်ပြီး ဘာမှမပြောင်းလဲ၊ မရွှေ့၊ မဖျက်ပါဘူး။ သူရေးတဲ့ဖိုင်တွေက သင်သိမ်းထားတဲ့ playlist တွေပဲရှိပါတယ်။
• သင့်ဘာသာစကားကို ပြောနိုင်ပါတယ်- အာရဗီ၊ ဟိန္ဒီနဲ့ ဆွာဟီလီကနေ အင်ဒိုနီးရှား၊ ဗီယက်နမ်နဲ့ ဇူးလူးအထိ ဘာသာစကား ၁၀၀ ကျော်ရှိပါတယ်။

audiobook တွေနဲ့ album တွေအတွက် ပြုလုပ်ထားပါတယ်
• Playback speed က 0.5× ကနေ 2.0× အထိရှိပြီး item တစ်ခုစီအတွက် save လုပ်ထားပါတယ်။ ၁၅ စက္ကန့်ကျော်ခြင်း
• ရှာဖွေဘား၊ အခန်းစာရင်းနှင့် အသိပေးချက်တွင် M4B နှင့် M4A အခန်းများကို ရှာဖွေပါ
• ပိုကြာကြာနားပြီးနောက် ဆက်လက်လုပ်ဆောင်သည့်အခါ စက္ကန့်အနည်းငယ်ပြန်ရစ်ပါ
• ကွက်လပ်မရှိ ပြန်ဖွင့်ခြင်း; ဒစ်ခ်များစွာပါသော အယ်လ်ဘမ်များကို ဒစ်ခ်အစီအစဉ်အတိုင်း ဖွင့်ပါ

သင့်ဖိုင်တွဲများ၊ သင့်အစီအစဉ်
• ဖိုင်မန်နေဂျာကဲ့သို့ breadcrumbs၊ အကြိုက်ဆုံးများနှင့် A–Z ဘားဖြင့် ရှာဖွေပါ
• ဖိုင်တွဲများ၊ အယ်လ်ဘမ်များ သို့မဟုတ် သီချင်းများကို တန်းစီစာရင်းထဲသို့ထည့်ရန်နှင့် M3U သီချင်းစာရင်းအဖြစ် သိမ်းဆည်းရန် ပွတ်ဆွဲပါ
• သင်ရှိပြီးသား သီချင်းစာရင်းများကို ဖွင့်ပါ
• အယ်လ်ဘမ်တစ်ခုစီကို သီချင်းနံပါတ်၊ ဖိုင်အမည် သို့မဟုတ် ခေါင်းစဉ်အလိုက် စီပါ

သင်နားထောင်သည့်နေရာတိုင်း
• အသိပေးချက်တွင်၊ သော့ခတ်မျက်နှာပြင်တွင် (၁၅ စက္ကန့်ကျော်ခြင်းဖြင့်) နှင့် Bluetooth သို့မဟုတ် ကားခလုတ်များတွင် ထိန်းချုပ်မှုများ
• Android Auto: ကားထဲတွင် သင့်စာကြည့်တိုက်၊ အကြိုက်ဆုံးများနှင့် တန်းစီစာရင်းကို ရှာဖွေပါ
• Home-screen widget
• နားကြပ် သို့မဟုတ် သင့်ကားချိတ်ဆက်ပြီးသည်နှင့် ရွေးချယ်နိုင်သည် စတင်ဖွင့်ပါ
• ကြိုတင်သတ်မှတ်ထားသော အသံများ၊ အလင်းနှင့် အမှောင် အပြင်အဆင်ပါသော Equalizer

ဖော်မတ်များ- FLAC၊ M4A၊ M4B (ကုဒ်ဝှက်မထားသော AAC)၊ MP3၊ OGG၊ Opus နှင့် WAV။

ဒီဇိုင်းအရ သီးသန့်
Retro Player မှာ အင်တာနက်ခွင့်ပြုချက်မရှိတာကြောင့် သင့်ဖုန်းကနေ ဘာမှမထွက်ပါဘူး- ကြော်ငြာတွေ၊ ခွဲခြမ်းစိတ်ဖြာမှုတွေ၊ ခြေရာခံမှုတွေ ဒါမှမဟုတ် အကောင့်တွေ မရှိပါဘူး။ သိုလှောင်ခွင့်ပြုချက်လည်း မလိုအပ်ပါဘူး။

အခမဲ့နဲ့ open source software (GPL-3.0 နဲ့အထက်)။ အသုံးပြုသူလမ်းညွှန်နဲ့ source code: https://github.com/r-e-t-r-o-p-l-a-y-e-r/retroplayer
