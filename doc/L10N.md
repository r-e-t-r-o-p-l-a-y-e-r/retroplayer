# Localization (l10n)

Retro Player ships **46** app UI languages (see `lib/domain/supported_locale_codes.dart` and `lib/l10n/app_locale_catalog.dart`). Endonyms in the language picker are **not** translated—they always appear in the target language.

## Files

- Template: `lib/l10n/app_en.arb`
- Generated: `lib/l10n/app_localizations*.dart` via `flutter gen-l10n`
- Sync keys into all locales: `dart run scripts/sync_l10n_arbs.dart` then `flutter gen-l10n`
- Machine-translate from English: **[L10N_MT_CLOUD.md](L10N_MT_CLOUD.md)** (DeepL + optional Google Cloud / Azure; credentials in **`.env`**)

Non-English ARB files may be MT from English; native-speaker improvements via PR are welcome.

## English copy (before machine translation)

Short UI strings are easy to mistranslate. Prefer **unambiguous** English in `app_en.arb` and add `@key.description` for translators/MT where helpful.

**Automatic MT context:** `scripts/mt_l10n_arbs.py` reads `@key.description` (or optional `@key.x-mt-context`) from `app_en.arb` and sends it with every cloud translation—**DeepL** uses the API `context` field; **Google Cloud** and **Azure** get a second line `[Context: …]` and only the **first line** of the result is stored in the ARB. You do not need to check TR/KO by hand for preset labels if descriptions are set.

| Risk | Keys | English approach |
|------|------|------------------|
| Manual = handbook | `eqManually` | **Manually** (custom EQ), not “Manual” |
| Bass = fish | `eqBass` | **Bass** (keep label short; use `@eqBass.description` for MT) |
| Treble = sport / triple | `eqTreble` | **Treble** + description |
| Voice = TTS / generic | `eqVoice` | **Voice** + description |
| Light = lamp / weight | `themeLight` | **Light mode** |
| System = vague | `themeSystem`, `languageSystem` | **System theme** / **System language** |
| Bands = music group | `bands` | **EQ bands** |
| Reset = database | `reset` | **Reset bands** (equalizer only) |
| Index = book index | `libraryIndex` | **Alphabetical index** (A–Z sidebar) |

After changing English wording, sync and re-translate affected keys, e.g.:

```bash
dart run scripts/sync_l10n_arbs.dart
python3 scripts/mt_l10n_arbs.py --backend deepl --keys eqBass --keys eqTreble --keys eqVoice --keys eqManually --keys themeLight --keys themeDark --keys themeSystem --keys languageSystem --keys bands --keys reset --keys libraryIndex
flutter gen-l10n
```

Or run `./scripts/update_l10n_locales.sh` for a full refresh.

Strings that are **fine but often stay identical** in European languages: `album`, `audio`, `pause`, `playlist`, `errorMessage` prefix, brand `appTitle`.

## MT workflow (summary)

See the full runbook in [L10N_MT_CLOUD.md](L10N_MT_CLOUD.md). Typical sequence after adding strings:

1. `dart run scripts/sync_l10n_arbs.dart`
2. `python3 scripts/repair_l10n_arbs.py`
3. `python3 scripts/mt_l10n_arbs.py --backend deepl --fill-english-only`
4. `python3 scripts/mt_l10n_arbs.py --backend deepl --icu-only`
5. `flutter gen-l10n`
6. `flutter test test/ui/l10n/`

Put API keys in `.env` (from `.env.example`); the MT script loads them automatically.

One-shot refresh when credentials are ready:

```bash
chmod +x scripts/update_l10n_locales.sh   # once
./scripts/update_l10n_locales.sh
```

## Unicode

- All `.arb` files are UTF-8.
- User media tags and paths use existing UTF-8 handling (`lib/domain/text_encoding.dart`, playlist UTF-8).
- `AppTheme` sets `fontFamilyFallback` for multi-script UI (Noto families on Linux/desktop).

## User preference

- **System** (default): follows OS language when supported; otherwise Flutter fallback.
- Fixed language: stored as a language code in app prefs (`LocalePreference`).

## Manual check

After adding strings: Settings in `ar`, `zh`, and `hi`—confirm titles and the language list render legibly on your device (especially Linux).

## Tests

Automated coverage under `test/ui/l10n/` includes ARB parity, catalog/endonyms, settings smoke, RTL, theme fallbacks, and **ICU plural** strings (`icu_messages_test.dart`). See [AUTOMATED_TESTING.md](AUTOMATED_TESTING.md).
